    Troubleshooting · UD1¶

    1. Método profesional¶

    Definir flujo esperado
       ↓
Observar estado actual
       ↓
Localizar la capa del fallo
       ↓
Formular hipótesis
       ↓
Obtener evidencia
       ↓
Modificar una variable
       ↓
Validar

    2. Definir el flujo¶

    Antes de ejecutar comandos:

    ¿Quién quiere hablar?
¿Con quién?
¿Con qué protocolo?
¿A qué puerto?
¿Debería estar permitido?

    6. Caso 1 · Subnet pública sin ruta¶

    Datos:

    Public IPv4: sí
SG: correcto
IGW: creado

    Pero la Route Table solo contiene:

    10.0.0.0/16 → local

    Falta:

    0.0.0.0/0 → IGW

    7. Caso 2 · Asociación incorrecta¶

    rt-public es correcta, pero public-subnet está asociada a rt-private.

    El error está en la asociación, no en la ruta.

    8. Caso 3 · EC2 sin IPv4 pública¶

    Subnet pública, ruta correcta e IGW correcto, pero la instancia solo tiene 10.0.1.25.

    No existe conectividad IPv4 directa vía IGW.

    9. Caso 4 · EC2 privada sin Internet¶

    rt-private:

    10.0.0.0/16 → local

    No hay nada que reparar: es el comportamiento diseñado.

    10. Caso 5 · Dos VM Proxmox no comunican¶

    VM-A 192.168.50.10/24
VM-B 192.168.60.20/24
bridge = vmbr1

    Capa 2 correcta, capa 3 en redes distintas: falta routing.

    11. Tabla de diagnóstico¶

    Nivel Pregunta Herramienta
    Interfaz ¿Está activa? ip -br link
    IP ¿Es correcta? ip -br addr
    Red ¿Pertenece al CIDR correcto? cálculo
    Routing ¿Existe ruta? ip route
    Selección ¿Qué ruta usará? ip route get
    ICMP ¿Existe respuesta? ping
    Servicio ¿Responde la aplicación? curl
    AWS subnet ¿Es la correcta? consola/API
    AWS routing ¿Tabla y asociación correctas? Route Tables
    Internet ¿Existe IGW y ruta? VPC
    IPv4 pública ¿Está asignada? EC2/ENI
    Seguridad ¿Está permitido el flujo? Security Group

    12. Regla de oro¶

    No tocar todavía

    Antes de cambiar ninguna configuración debes poder responder:

    1. Qué resultado esperabas.
    2. Qué resultado has obtenido.
    3. En qué punto del camino crees que se produce la diferencia.
    4. Qué evidencia respalda tu hipótesis.

    Reconstruir el recorrido del paquete y localizar el primer punto donde la realidad deja de coincidir con el diseño.
